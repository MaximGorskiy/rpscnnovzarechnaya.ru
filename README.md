# Сайт Заречной общины

Статический сайт без CMS, базы данных, внешних шрифтов и сторонних скриптов. Открывается через `index.html` и работает на обычном бесплатном хостинге. Изображения взяты из предоставленного архитектурного проекта; это визуализации, не фотографии стройки.

## Обновление

Каждое изменение сохраняем в Git отдельным коммитом с понятным описанием: что изменено на сайте и зачем. После проверки коммит отправляется в GitHub через Push origin в GitHub Desktop.

Просите Codex внести изменения в этой папке. Подготовьте дату отчёта, выполненные работы, планы и реальные фотографии. Основные меняющиеся данные находятся в `content.js`, постоянные тексты — в `index.html`. Не нужно устанавливать Node.js или компилировать сайт.

В `content.js` заполните подтверждённые `currentStage`, `updatedAt`, `nextStage`, `phone`, `email`, `contactPerson`, `donationDetails`, `donationText`, `scheduleText`. Добавляйте записи в `reports` и фотографии в `constructionPhotos` по примерам в начале файла. Даты — YYYY-MM-DD, пути фотографий — assets/building/имя.webp (латиницей). Новые отчёты автоматически появляются первыми. Нет введённых реквизитов — нет платёжной кнопки. Форм отправки и сбора данных в этой версии нет. Контакты включаются только после заполнения.

## Основное размещение: GitHub Pages

Локальный Git-репозиторий содержит исходники и публичные файлы сайта. Временные скриншоты и ZIP-архив исключены через `.gitignore`. `.nojekyll` отключает обработку сайта Jekyll.

Копия сайта создана 14 октября 2026 года из репозитория `MaximGorskiy/rpsc-nnov`. Содержимое сохранено; файл CNAME и адрес для кнопки «Поделиться» при локальном просмотре используют новый домен.

Репозиторий: https://github.com/MaximGorskiy/rpscnnovzarechnaya.ru. Основной адрес: https://rpscnnovzarechnaya.ru/.

GitHub Pages публикует ветку `main`, папку `/(root)`. Custom domain: `rpscnnovzarechnaya.ru`. DNS обслуживает Cloudflare: четыре A-записи GitHub Pages для корня и CNAME `www` → `maximgorskiy.github.io`.

Обычное обновление: получить изменения `git pull --ff-only`, отредактировать сайт локально, проверить `git diff`, выполнить `git add` для изменённых файлов, `git commit -m "Описание изменения"`, затем `git push`. `git fetch origin` только получает сведения об удалённых изменениях; он не отправляет локальные коммиты и не меняет рабочие файлы.

Репозиторий публичен, поэтому в него нельзя добавлять пароли или приватные сведения. Жёлтые заглушки сейчас входят в сайт и будут доступны посетителям при публикации. Исходный архитектурный PDF хранится локально вне репозитория и не публикуется, поскольку посвящение храма ещё не утверждено. Перед внешней публикацией проверить состав материалов.

## Проверка и упаковка

`python tools/check_site.py` проверяет локальные ссылки и формирует `site-upload.zip` только из публичных файлов. Для предпросмотра: `python -m http.server 8080 --bind 127.0.0.1`, затем открыть http://127.0.0.1:8080. Python для работы самого сайта не нужен.

Сайт намеренно не содержит вымышленных отчётов, фотографий стройки, точного номера дома, расписания, реквизитов или контактных лиц. По просьбе пользователя недостающие данные выделены яркими жёлтыми заглушками. Заглушки автоматически исчезают после заполнения соответствующих полей в content.js. Контактное лицо можно указать рядом с телефоном в HTML или расширить данные при следующем обновлении. Даты и основные характеристики проекта взяты из комплекта АР 0143.03.2023, 2024 год, ООО «Творческая мастерская архитектора Иняева А. А.».


## Реквизиты и файл для ознакомления — 16 октября 2026

Банковские реквизиты и контакты перенесены из предоставленной общиной карточки предприятия. Поля находятся в `content.js` → `donationDetails`, контакты — `phone`, `email`, `contactPerson`. Назначение платежа в карточке отсутствует, поэтому на сайте не предлагается вымышленное назначение. Юридический адрес получателя указан отдельно от адреса строительства.

Для отправки сайта одним файлом выполните `python tools/build_single_file.py`. Результат: `output/zarechnaya-obshchina.html`. Отправьте сам HTML как документ/файл. Получатель сохраняет его и открывает двойным щелчком в браузере: распаковывать архив или искать index.html не нужно. При необходимости: «Открыть с помощью» → браузер. Мессенджер может потребовать сначала скачать вложение. На телефоне поддержка открытия локальных HTML зависит от приложения и браузера.

Все изображения, стили и скрипты встроены в файл; для чтения интернет не требуется. Галерея и навигация сохраняются. Карта в автономной копии заменена адресом и ссылкой: переход в Яндекс Карты требует интернета. Это копия на момент сборки, без автоматических обновлений. После правок создайте файл заново. Папка `output` исключена из Git, исходники и обычная публикация сайта сохраняются отдельно.
