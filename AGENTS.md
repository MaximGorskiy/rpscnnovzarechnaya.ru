# Порядок работы с сайтом

- Все изменения готовить локально и сохранять отдельным Git-коммитом с понятным описанием: что изменено и зачем.
- Не выполнять `git push`, публикацию, запуск удалённого деплоя или изменение настроек опубликованного сайта. Пользователь сам отправляет коммиты на GitHub и публикует сайт после согласования.
- После каждого изменения сайта запускать `python tools/check_site.py`.
- Папку `output` не добавлять в Git.
- В ответе кратко описывать изменения и проверку, указывать локальный коммит. Явно сообщать, что публикация не выполнялась.
- Реквизиты и контакты переносить только из подтверждённых пользователем источников; отсутствующие сведения не выдумывать.
